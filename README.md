# binatech-algene-pilot
BinaTech contractor pilot workspace — isolated frontend work with synthetic data; no production access.

## Start here

The exact previously delivered Starter-02 package is in [starter-02](starter-02/README.md). Read its complete README before making changes. Its original file manifest is retained; no application history, credentials or production backend is included.

Run the project from `starter-02/source`, following the package instructions. Keep changes within the accepted v3 pilot scope and work on a named branch, then open a pull request against this repository's `main` for review. Do not merge or publish without Karim's approval. This is a working rule, not an enforced branch-protection guarantee on the current repository plan.

This repository's `main` is the isolated pilot baseline, not BinaTech's production branch. Do not add deployment workflows, secrets, real customer data or production integrations. The existing scope, fee and acceptance terms are unchanged. Preserve an untouched starter baseline for comparison.
